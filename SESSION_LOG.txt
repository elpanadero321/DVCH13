## 1. Qué es el proyecto

DVCH = modelo cosmológico de **interacción CDM–vacío** con cerradura de
Friedmann implícita. Cerradura homogénea (núcleo físico):

```
E2 = Omega_r0*(1+z)^4 + Om_z + OL_z
OL_z = OL * (Om_z/Om)^n * (1+beta) / (1 + beta*E2)   (punto fijo)
```

ΛCDM es el **caso anidado exacto**: con `n=0, beta=0` → `OL_z = OL`.

La materia NO evoluciona como Om*(1+z)^3: se integra la ecuación de
conservación CDM–vacío (Q != 0), igual que `dvch_camb_background.py`.
(Esto es lo que integra el ajuste; ver sección 2.)

Parámetros tardíos: `Om, H0, M, n, beta, rd` (r_d marginalizado).

Política de integridad: **nunca se reportan números que no provengan de
una corrida real.** Todo lo que sigue la cumple.

## 7. DIAGNOSTICO ESTRUCTURAL FINAL (2026-11-07)

Pregunta: ¿el fracaso del modelo es reparable (formula/hipotesis) o es una
exclusion estructural? Ensayada la variante switch S(z)=1/(1+((1+z)/(1+z_c))^p)
que desacopla el vacio del LCDM a z>z_c (en dvch_vs_lcdm_real.py y en el
CAMB externo via env DVCH_ZC/DVCH_P; cerradura cuadratica exacta).

Resultado trade-off (dvch_switch_tradeoff.csv, _cmb_tradeoff.sh):
- z_c=1:  dchi2_late=-3.92 (n=0.324, beta=0.289, Om=0.379), dchi2_CMB=+5.4e4
- z_c=1.5,2,5,inf: dchi2_late ~ -3.55..-3.60, dchi2_CMB +6.1e4..+6.8e4
Ningun z_c rescata el CMB.

Mecanismo (verificado: CAMB Fortran == referencia Python == integracion RK4
propia hasta z=1100): la conservacion exacta CDM-vacio transfiere energia
vacio->materia a tiempos tardios, de modo que rho_m a^3 NO es constante:
x/(1+z)^3 se satura en un valor <1 para siempre (no se recupera):
  Om=0.30 n=0.52 b=1.10 -> 0.707 (deficit -29%), H(z) -12..-15%, theta* -4.7%
  Om=0.38 n=0.42 b=0.53 -> 0.832 (-17%)  [best-fit tardio]
  Om=0.30 n=0.097 b=0.10 -> 0.987 (-1.3%) [best-fit del CMB]
  Om=0.315 n=0.01 b=0.01 -> ~1.0
El deficit escala con n y Om conjuntamente. El ajuste tardio (dchi2=-3.6)
requiere el regimen con deficit 15-30%, que el CMB destruye (theta*, r_drag,
era de materia: chi2 +1e4..1e5). Para conservar a^-3 hace falta n<0.1, que es
exactamente donde la mejora tardia desaparece.

Conclusion: la hipotesis (cerradura del vacio x^n con conservacion exacta)
es estructuralmente incompatibile con el CMB; no es un bug ni un error de
datos, y ninguna variante de desacoplamiento z_c>=1 lo resuelve. El undo
unico donde el modelo sobrevive (n->0) es indistinguible de LCDM.

Script de diagnostico: _diag_ode_wide.py (ODE hasta z=1100), _diag_cmb.py
(espectros/parametros derivados CAMB), _diag_pathology.py (mapa de deficit).
