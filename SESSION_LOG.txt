## 1. Qué es el proyecto

DVCH = modelo cosmológico de **interacción CDM–vacío** con cerradura de
Friedmann implícita. Cerradura homogénea (núcleo físico):

```
E2 = Omega_r0*(1+z)^4 + Om_z + OL_z
OL_z = OL * (Om_z/Om)^n * (1+beta) / (1 + beta*E2)   (punto fijo)
```

ΛCDM es el **caso anidado exacto**: con `n=0, beta=0` → `OL_z = OL`.

La materia NO evoluciona como Om*(1+z)^3: se integra la ecuación de
conservación CDM–vacío (Q != 0), igual que `dvch_camb_background.py`.
(Esto es lo que integra el ajuste; ver sección 2.)

Parámetros tardíos: `Om, H0, M, n, beta, rd` (r_d marginalizado).

Política de integridad: **nunca se reportan números que no provengan de
una corrida real.** Todo lo que sigue la cumple.

## 10. GENERALIZACION a1/a2 + CRECIMIENTO (2026-11-13)

Bugs arreglados:
1. Las funciones de densidad hacian cast a float -> la derivada por paso
   complejo daba 0 y el test de conservacion 'pasaba' sin probar nada.
2. El assert de equivalencia con DE desacoplada usaba tolerancia ABSOLUTA
   (valores ~1e16 en a=1e-4). Ahora relativa.
3. EL GROSERO: el sistema de crecimiento tenia 4 variables (dc, db, hp, hpp)
   con d(hp)/dN = hp (en vez de hpp) - crecimiento exponencial espurio.
   La ecuacion de Einstein en gauge sincrono es una RESTRICCION entre las
   variables, no una ecuacion de evolucion: integrar su derivada genera un
   modo espurio. Sistema cerrado correcto: 3-D (dc, db, hp):
     d dc/dN = -hp/2 - q dc ; d db/dN = -hp/2
     d hp/dN = -(2+dlnH/dN) hp - 3(rc dc + rb db)/E2
   + ICs en modo creciente: hp = -2 delta.
   TEST FUERTE: a1=a2=0 reproduce la ec. de crecimiento estandar de LCDM a
   1.3e-11 (antes: -160% / +28%). Verificado en _test_growth_ic.py.
